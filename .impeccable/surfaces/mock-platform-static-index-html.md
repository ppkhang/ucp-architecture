Mock shop UI. Mode: Operate (control panel, my orders), with a simple storefront and the sign-in and payment pages. Audience: demo viewers and Khang testing, switched by a toggle. English. Code-led.

## Direction

Replaced on 2026-11-25. Khang rejected the parcel waybill version as ugly; this one was built with UI UX Pro Max (minimal style, Rubik and Nunito Sans). White cards with soft shadows, purple as the main color, one compact row per order that opens for details, a dotted progress line, and a tinted labelled strip for test controls.
